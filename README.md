# McDonald's Clone Coding

React를 활용하여 맥도날드 코리아 웹사이트의 주요 UI와 기능을 구현하는 클론 프로젝트입니다.

## Features

- 메인 배너 슬라이드
- 메뉴 섹션 UI
- Footer 구현
- React State 기반 슬라이드 제어
- 반응형 레이아웃 구현 예정

## Tech Stack

| Technology | Description |
|------------|-------------|
| React | UI 개발 |
| Vite | 개발 환경 |
| JavaScript | 로직 구현 |
| CSS | 스타일링 |
